# Contributing

Thank you for improving BioHub Cell Tracking.

## Before opening a pull request

1. Create a focused branch from `main`.
2. Keep changes small and explain the biological or technical motivation.
3. Add or update tests for behaviour changes.
4. Run `pytest` and include the result in the pull request description.

## Pull request expectations

Use clear, reproducible examples. Do not commit source microscopy data, model checkpoints, API keys, or generated submission files.

## Reporting bugs

Please use the bug-report template and include the command, Python version, dependency versions, and a minimal non-sensitive example.
